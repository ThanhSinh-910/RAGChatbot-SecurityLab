# Archived legacy PDFs

The 28 `DOC001.pdf`–`DOC028.pdf` files in this folder were the old demo corpus
for the chatbot. Their first pages identify the fictional institution
“Đại học Kỹ thuật Sông Hàn”. The active chatbot now uses the reviewed QĐ1416
VKU corpus at `experiments/data/real_vku/chunks/QD1416-demo-corpus.jsonl`.

These PDFs are retained for reference and can be restored if needed. They are
not used by `web.py` or `app.py`.
